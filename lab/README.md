# DAA Lab Solutions

This directory contains lab-focused material.

```text
lab/
  how_to_solve/       # explanation + algorithm for each lab problem
  implementations/    # runnable Python implementations
```

Run any implementation like:

```bash
python3 lab/implementations/02_iterative_merge_sort.py
```

Lab list:

1. Execution time measurement
2. Iterative Merge Sort
3. Random weighted graph generator
4. Priority queue using MinHeap
5. MST algorithms: Kruskal and Prim
6. Dijkstra SSSP
7. Huffman Coding
8. Optimal Merge Pattern
9. Fractional Knapsack
10. 0/1 Knapsack DP with `C[][]` and `Keep[][]`
11. LCS DP with constructed tables
