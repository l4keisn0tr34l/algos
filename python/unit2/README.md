# Unit II Python Practice

This folder is split into two parts:

```text
problems/   # LeetCode-style prompts with TODO stubs only
solutions/  # completed reference solutions
```

## How to use

Start with `problems/`.

Example:

```bash
python3 python/unit2/problems/01_binary_search.py
```

It will fail until you implement the function. After attempting, compare with:

```text
python/unit2/solutions/01_binary_search.py
```
